# 해외 유튜브 시장 공략집

작성: 2026-09-27 · 상태: ① 레퍼런스 탭, ② 상품 녹이기 탭 구현 완료 (2026-09-30), ③ 스토리보드·소스부터 남음

이 문서는 세 가지를 한곳에 모은 것이다.

1. 어느 나라를 노릴지 (시장 분석)
2. 무엇을 올릴지 ("광고 아닌 것 같은 광고" 기획 엔진)
3. 어떻게 싸게 만들지 (스토리보드 + 소스 조달)

---

## 1. 한 줄 전략

> 베트남·태국·미국에서 터진 쇼츠 포맷을 캐서, 상품을 소품으로 녹인 뒤, **일본·대만**처럼 단가는 높고 경쟁은 적은 시장에 올린다. 영상은 그냥 웃긴 쇼츠고, 판매는 "그거 어디 거예요?" 댓글에서 시작한다.

- 수익 구조: **상품 판매(주)** + 쇼츠 광고 수익(부). 쇼츠 RPM은 어디든 낮다. 단가가 높은 나라는 시청자의 구매력도 높다는 뜻이라 상품 판매에서 더 벌린다.
- 원칙: 광고 티는 안 내되, 광고 표시는 나라별 법대로 한다. 숨기는 게 아니라 늦게 알려주는 것.

## 2. 시장 분석 (2026-09 기준)

### 2.1 국가 비교표

| 나라 | 유튜브 이용자 | 쇼츠 RPM(추정) | 100만 구독 채널 | 인구 100만 명당 | 판정 |
|---|---|---|---|---|---|
| **일본 JP** | 7,900만 | $0.14 | 350~500 | **3~4개** | **1순위** |
| **대만 TW** | 1,800만 | $0.14 | 약 200 (추정) | 9개 | **2순위** |
| 한국 KR | 4,600만 | $0.19 | 약 800 (추정) | 15개 | 홈 시장 |
| 홍콩 HK | 650만 | $0.15 | 180 | 24개 | 대만 채널로 커버 |
| 미국 US | 2억 5,900만 | $0.08~0.20 | 약 14,000 | 43개 | 고단가·고경쟁 |
| 호주 AU | 2,100만 | $0.10~0.15 | 500+ | 19개 | 영어권 묶음 |
| 베트남 VN | 6,200만 | $0.02~0.04 | 2,500+ | 25개 | 레퍼런스 광산 |
| 태국 TH | 4,700만 | $0.02~0.05 | 약 1,500 (추정) | 21개 | 레퍼런스 광산 |
| 독일어권 DE+CH+AT | 독일 6,500만+ | $0.12~0.16 | 약 900 (추정) | 11개 | 나중 |
| 스위스·노르웨이·덴마크 | 각 400~700만 | $0.12~0.16 | 각 30~40 (추정) | 4~6개 | 시장이 작아 보류 |

**기회 지수** = 이용자 수 × 쇼츠 RPM ÷ 100만 구독 채널 수 (상대값). 높을수록 "먹을 파이는 큰데 먹는 입은 적다".

- 상위: 일본, 스위스·노르웨이·덴마크, 대만, 싱가포르, 한국
- 하위: 베트남, 태국, 미국 (채널이 너무 많음)

### 2.2 읽는 법

- **일본이 압도적.** 인구 1억 2천만, 이용자 7,900만인데 100만 채널이 500개도 안 된다. 인구가 비슷한 베트남이 2,500개다. 경쟁이 5분의 1이고 쇼츠 RPM은 한국 다음 수준. 한국 포맷이 잘 먹히는 시장이기도 하다.
- **대만**은 시장은 작지만 단가가 일본급, 채널 밀도는 한국의 절반. 번체 중국어라 홍콩까지 같이 먹는다.
- **베트남·태국**은 반대. 채널은 많고 단가는 일본의 4분의 1. 돈 벌 시장이 아니라 **포맷 캐는 시장**. 여기서 터진 걸 일본·대만에 이식한다.
- **미국·호주**는 단가는 높은데 경쟁이 제일 심하다. 영어권은 한 채널로 묶어서 나중에.
- **스위스·노르웨이·덴마크**는 단가 최상위에 채널이 거의 없지만 시장이 너무 작고 언어가 제각각. 독일어권(독일+스위스+오스트리아 = 약 1억)으로 묶을 때만 의미 있다.

### 2.3 주의

- 구글은 공식 단가를 내지 않는다. RPM은 매체마다 최대 3배까지 다르다. 순위는 믿을 만하지만 숫자는 참고용.
- "(추정)"이라 적은 채널 수는 공식 집계가 없어서 잡은 값이다. 분기마다 갱신할 것.
- 쇼츠 RPM은 롱폼 RPM의 10분의 1 수준이다. 롱폼 RPM(호주 $7.5, 노르웨이 $7~16, 스위스 $6~12, 미국 $6.7~12, 일본 $3.0, 홍콩 $3.9, UAE $2.75)과 섞어 보지 말 것.

### 2.4 공략 순서

1. **일본** — 첫 해외 채널. 한국어 대본 → 일본어 자막·더빙.
2. **대만(+홍콩)** — 번체 자막. 일본 채널이 굴러가면 같은 파이프라인으로 복제.
3. **영어권(미국·호주·캐나다·영국)** — 단가는 최고지만 경쟁도 최고. 포맷이 검증된 뒤.
4. **독일어권** — 나중.
5. **베트남·태국** — 채널을 열지 않는다. 수집만 한다.

## 3. 나라별 실행 메모

### 3.1 공통

- **나라마다 채널을 따로 연다.** 쇼츠 추천은 언어·지역 단위로 돌아서 한 채널에 여러 언어를 섞으면 알고리즘이 헷갈린다.
- **자막이 먼저, 더빙은 나중.** 쇼츠는 무음 시청이 많고 화면 자막이 웃음의 절반이다. 더빙은 AI 더빙(ElevenLabs 등)으로 붙이되 자막 없이 올리지 않는다.
- **업로드 시간**: 현지 시간 저녁 7~11시. 일본(JST)은 한국과 같고, 대만은 한 시간 늦다.
- **판매 동선은 나라마다 다르다.** 영상 안에는 링크·구매 언급이 없고, 고정 댓글·설명란·프로필 링크로 판다.

| 나라 | 판매 링크 | 광고 표시 규정 |
|---|---|---|
| 일본 | Amazon JP 어필리에이트, 楽天 | 景品表示法 스텔스 마케팅 규제(2023.10 시행). 「PR」「広告」 표기 필수 |
| 대만 | 蝦皮(Shopee), momo | 公平會 추천·보증(薦證) 광고 규범. 業配 표시 필수 |
| 미국 | Amazon Associates | FTC 보증 가이드. #ad, #sponsored |
| 한국 | 쿠팡 파트너스, 자사몰 | 표시광고법·추천보증 심사지침. "유료광고 포함" + 쿠팡 파트너스 문구 |
| 베트남·태국 | Shopee, TikTok Shop, Lazada | 베트남은 2026년 광고법 개정으로 인플루언서 표시 의무 강화. 태국은 확인 필요 |

- 유튜브 자체 "유료 프로모션 포함" 체크는 모든 나라에서 켠다.

### 3.2 일본

- 화면 자막 밀도가 높다. 한국 쇼츠보다 자막을 더 크게, 더 자주.
- 「〇〇してみた」(해봤다), 랭킹, 생활 꿀팁, ASMR, 비포·애프터 포맷이 강하다.
- 직접 비교 광고, 경쟁사 언급은 피한다. 상품은 "쓰다 보니 좋았다" 톤.
- 상품 소품이 일본에서 사기 쉬운 것이어야 한다. Amazon JP에 있는지 먼저 확인.

### 3.3 대만

- 번체 중국어. 간체로 올리면 바로 티 난다.
- 한류 친화. 한국 제품·한국식 포맷 자체가 소구점.
- 홍콩 시청자가 같이 들어온다. 광둥어 더빙은 안 해도 자막으로 커버된다.

### 3.4 베트남·태국 (수집 전용)

- 인기 차트에서 3분 이하만 남기면 쇼츠 후보가 된다.
- 여기서 터진 포맷은 제작비가 싸고 감정선이 단순해서 이식이 쉽다.
- 댓글 반응까지 같이 가져와서 "어디서 웃었는지"를 포맷 카드에 남긴다.

## 4. 수집: 쇼츠레이더 국가별 확장

쇼츠레이더는 사용자 PC에 있고 이 저장소에 없다. 아래는 넣을 사양.

### 4.1 국가 설정

| 나라 | regionCode | relevanceLanguage |
|---|---|---|
| 한국 | KR | ko |
| 일본 | JP | ja |
| 미국 | US | en |
| 베트남 | VN | vi |
| 태국 | TH | th |
| 대만 | TW | zh-Hant |

### 4.2 수집 방식과 쿼터 (하루 10,000유닛)

- **인기 차트**: `videos.list?chart=mostPopular&regionCode=XX` — 호출당 1유닛, 나라당 최대 200개. 길이 3분 이하만 남기면 쇼츠 필터. 6개국 × 4페이지 = 24유닛. 한 시간마다 돌려도 하루 600유닛.
- **키워드 검색**: `search.list` + `regionCode` + `relevanceLanguage` + `videoDuration=short` + `order=viewCount` + `publishedAfter` — 호출당 100유닛. 나라마다 그 나라 언어로 키워드를 넣어야 잡힌다. 6개국 × 키워드 2개 = 1,200유닛. 하루 한 번.
- **댓글**: `commentThreads.list` — 1유닛에 100개. API 키만으로 된다(OAuth 불필요).
- 저장 컬럼 추가: `country`, `collected_at`. 같은 영상이 여러 나라에서 잡히면 나라별로 따로 기록.

### 4.3 점수

- **속도** = 조회수 ÷ 경과 시간
- **아웃라이어** = 조회수 ÷ 채널 구독자 수
- **기회 지수(나라)** = 이용자 수 × 쇼츠 RPM ÷ 100만 채널 수. 단가·채널 수 표는 분기마다 손으로 갱신.
- **현지 공급 부족 지표** = 그 나라 인기 차트에서 외국어 쇼츠 비율. 높을수록 현지 크리에이터가 부족하다는 뜻이라 기회.
- 순위는 나라별로 따로 매긴다. 같은 포맷이 어느 나라에서 먼저 터졌는지 보인다.

### 4.4 못 하는 것

- 다른 사람 영상의 자막은 YouTube Data API로 못 받는다(영상 주인 OAuth 필요). 자막·장면 분석은 5장의 Gemini 경로로 한다.

## 5. 레퍼런스 해부: 링크 → 포맷 카드

### 5.1 경로

1. **링크 → Gemini 영상 분석 (메인)**: Gemini API는 공개 유튜브 링크를 그대로 입력으로 받는다. 다운로드·자막 불필요. Script Studio에 있는 Gemini 키 입력을 그대로 쓴다. 대사뿐 아니라 컷 전환, 화면 자막, 그래픽, 효과음 타이밍까지 뽑힌다. 베트남어·태국어·중국어 영상은 한국어로 번역해서 카드를 만든다.
2. **YouTube Data API → 숫자·댓글 (보강)**: 조회수, 길이, 업로드일, 댓글 100개. 댓글이 "왜 터졌나"의 답이다.
3. **실패 시**: 비공개·연령제한 영상은 mp4 업로드(Gemini Files) 또는 자막 붙여넣기.

### 5.2 비용

- 영상 1초 = 263토큰. 1분 쇼츠 ≈ 1만 6천 토큰.
- Gemini 3 Flash: 1분 쇼츠 1개 해부 ≈ $0.02~0.06 (생각 토큰·초당 2프레임 포함). 100개 ≈ $2~6. 카드마다 실제 토큰과 비용이 표시된다.
- Gemini 3.1 Pro: ≈ $0.08 (110원).
- 무료 등급 키: 유튜브 링크 하루 8시간(1분 쇼츠 480개)까지 무료. 단 분당 요청 제한이 있고 구글이 입력을 제품 개선에 쓸 수 있다.
- 링크 가져오기 기능 자체는 프리뷰라 추가 요금 없음. 토큰값만.
- 기본 모델은 3 Flash. Pro는 필요할 때만.

### 5.3 포맷 카드 스키마

```
메타: 링크, 채널, 나라, 조회수, 길이, 업로드일, 댓글 반응 요약(어디서 웃었나 / 뭘 물어보나)
훅(0~3초): 대사, 화면, 자막, 훅 유형(사연·위협·황당 전제·궁금증)
비트[]: 시작~끝 초, 대사, 화면, 자막, 그래픽, 효과음, 역할(설정/고조/펀치)
리듬: 변화 간격 평균(초), 컷 수, 펀치 위치(%)
소품 슬롯[]: 비트 번호, 물건, 역할(도구/반전/배경)
왜 터졌나: 3줄
재사용 뼈대: 제품 무관 템플릿(비트 구조 + 시간 비율 + 훅 예시 2~3개)
```

- 카드는 브라우저 라이브러리에 쌓인다. 쇼츠레이더 링크를 넣을수록 해부된 포맷이 늘고, 이게 엔진의 연료다.

## 6. 기획 엔진: 상품 녹이기

### 6.1 개념

잘 터진 쇼츠의 **구조를 빌리고**, 소품 자리에 **상품을 끼운다**. 상어 퇴치법 쇼츠라면 3번째 방법이 "우산을 확 펴라"가 되고, 그 우산이 파는 물건이다. 영상은 그냥 웃긴 쇼츠, 판매는 "저 우산 뭐예요?" 댓글에서 시작.

범용이 되는 이유: 제품 지식은 코드에 하나도 안 넣는다. 포맷 뼈대(비트 구조, 시간 비율, 훅 예시, 언제 쓰는지 규칙)만 박아 두고 AI가 살만 채운다. 새 광고 유형이 필요하면 포맷을 하나 더 넣으면 된다.

### 6.2 입력

- 레퍼런스: 포맷 카드(5장) 또는 대본 붙여넣기
- 상품: 이름, 카테고리, 뭐 하는 물건인지, 눈에 띄는 특징(모양·색·동작), 제일 잘하는 것 1개, 판매 링크
- 타깃 나라·언어, 채널 톤(웃김/정보/브이로그/콩트)
- 조건: 브랜드명 언급 횟수, 금지 표현

### 6.3 4단계 (API 호출)

1. **긴장 추출** — 상품이 "답이 되는 문제"를 3~5개. 반전 광고는 상품이 답이어야 성립한다.
2. **포맷 매칭 + 상품 역할** — 6개 포맷에 점수. 상품이 슬롯에서 할 역할 3개(해결 도구 / 반전 아이템 / 캐릭터 습관 소품). 상품의 기능은 영상의 **행동으로 보여야지 설명되면 안 된다.**
3. **컨셉 3개** — 훅(3초) / 위장 장르 / 긴장 쌓기 / 반전 지점(%) / 반전 후 메시지 / CTA / 루프 장치 / **제작 난이도(촬영 n컷·스톡 n컷·AI n컷)**.
4. **대본 + 판매 동선 + 자체 검수** — 고른 컨셉을 타임코드까지 풀고, 고정 댓글·설명란·후속 쇼츠 훅을 만들고, 9장 검수를 돌린다.

### 6.4 포맷 6종

| 포맷 | 한 줄 | 맞는 경우 |
|---|---|---|
| 반전 엔딩형 | 썰처럼 시작, 마지막에 제품이 펀치라인 | 쇼츠 기본값 |
| 문제 해결형 | 진짜 유용한 정보 8할, 제품은 해결책 중 하나 | 정보 채널 |
| 장르 위장형 | 뉴스·다큐·인터뷰·직장인 콩트처럼 시작 | 콩트 채널 |
| 메타형 | "광고 아니에요" 반복, 제품은 점점 대놓고 | 유머 브랜드만 |
| 실험·기록형 | "30일 써봤다" 일지 | 건강·뷰티·앱 |
| 시청자 답변형 | "댓글에서 제일 많이 물어본 그거" | 팬층 있는 채널 |

매칭 규칙 예: 쇼츠면 반전형·장르위장형 우선. 톤이 웃김이 아니면 메타형 제외. 건강·뷰티·금융이면 실험형 가산.

### 6.5 엔진이 강제하는 규칙

- 첫 3초 훅은 상품과 무관하게. 사연·감정·궁금증으로.
- **무광고 테스트**: 상품을 잘라내도 영상이 성립해야 한다. 아니면 '늦게 나오는 광고'다.
- 반전은 '끊김'이 아니라 '답'. 앞에서 쌓은 문제를 상품이 푼다.
- 반전 후는 짧게. 장점 1개 + CTA 1개. 30초 쇼츠면 반전 후 4~5초.
- 상품은 2~3번만 등장, **항상 이기는 쪽(긍정 역할)**. 놀림감·실패 쪽 금지.
- 영상 안에 구매·할인·링크 언급 금지. 상품 그래픽은 궁금증용("?" 팝, 작은 반짝임)만. "구매" 뱃지 금지.
- 레퍼런스는 **구조만** 빌린다. 대사·장면은 새로 쓴다. 그대로 베끼면 저작권과 유튜브 재사용 콘텐츠 정책에 걸린다.
- 광고 표시는 나라별 규정(3.1)대로 설명란·고정 댓글에 자동으로 붙인다.

### 6.6 판매 동선 (2편 구조)

- **1편**: 터진 포맷 + 상품 소품. 링크 없음. 고정 댓글: "우산 물어보시는 분 많아서 링크 걸어둠".
- **2편**: "댓글에서 하도 물어봐서" — 여기서 상품을 제대로 보여준다. 진짜 판매는 2편.
- 설명란: 나라별 링크 + 광고 표시 문구.

## 7. 스토리보드 + 소스 조달

기획이 컷 단위까지 끝나야 제작 단가가 떨어진다. 산출물은 **컷 단위 스토리보드 + 컷마다 소스 조달 방법**.

### 7.1 컷 하나당

- 시간(초), 구도(클로즈업/미디엄/풀), 카메라(고정/줌/팬)
- **영상 레이어**: 화면에 보이는 것, 행동
- **그래픽 레이어**: 자막 스타일(강조 단어, 크기·색, 등장 방식, 위치), 그래픽 요소(화살표·동그라미·말풍선·이모지·밈·넘버링·게이지), 카메라 효과(줌 펀치·흔들림·슬로우·프리즈), 트랜지션(컷·휩·글리치), 효과음 큐
- 대사/내레이션, 화면 자막
- 상품 등장 여부와 방식
- **소스 타입**: 촬영 / 스톡 / AI 생성 / 보유 소스 / 그래픽(소스 불필요)
- 소스 검색 키워드(영문) 또는 AI 생성 프롬프트(영문, 9:16)
- 대체안

### 7.2 소스 조달 원칙 (단가가 여기서 정해진다)

- **실제 상품이 나오는 컷만 촬영.** 나머지는 스톡·AI·그래픽. 상어/우산이면: 상어 = AI 생성 또는 스톡, 바다 = 스톡, 우산 원터치 펴짐 클로즈업 = 촬영, 리액션 = 촬영 1컷.
- 촬영 컷은 **촬영 리스트**로 따로 뽑아 한 번에 찍는다(장소, 소품, 동작). 3컷이면 폰으로 30분.
- 스톡은 무료 API가 있는 **Pexels, Pixabay**부터. 상업 사용 가능. Pexels는 세로(9:16) 필터가 된다. 엔진이 컷별 키워드로 직접 검색해서 후보를 썸네일로 보여준다.
- AI 생성은 못 찍는 것(상어, 폭발, 판타지)에만.
- **소스 라이브러리**: 상품 컷은 한 번 찍으면 태그 달아 저장("우산 펴짐 클로즈업", "우산 들고 걷기"). 다음 영상부터 라이브러리 먼저 검색 → 촬영이 0에 가까워진다.
- 텍스트 카드·비교표·다이어그램 컷은 소스 타입 "그래픽". 영상 소스가 아예 필요 없다.
- **채널 그래픽 프리셋**(폰트, 색, 자막 스타일, 효과음 팩)을 한 번 정해 두면 모든 스토리보드가 따른다.
- 자막은 타이밍이 있으니 **SRT**로 뽑아 CapCut·Vrew·프리미어에 바로 넣는다.

### 7.3 밋밋 감지 → 그래픽으로 채우기

- 화면 변화가 **2초 이상 없으면 밋밋**. 변화 = 컷 전환, 줌 펀치, 자막 팝, 그래픽 등장, 효과음+흔들림, 프리즈.
- 레퍼런스 해부에서 잘 터진 쇼츠의 변화 간격을 먼저 잰다(보통 1~1.5초). 그 리듬을 목표치로 삼는다.
- 원인별 처방: 말하는 컷 정적 → 키네틱 자막 + 줌 교차 + 이모지 / 스톡이 느림 → 2배속 + 줌 펀치 + 화살표 + 의미 자막 / 설명 구간 → 다이어그램·비교표 카드로 교체 / 단계 전환 → 넘버링 팝 + 휩 + 효과음 / 리액션 약함 → 프리즈 + 얼굴 확대 + 밈 팝.
- **예외**: 펀치 직전 0.5~1초는 일부러 비운다. 빌드업이지 밋밋이 아니다.
- 출력: 0.5초 단위 이벤트 타임라인. 빈 구간이 막대로 보인다.

### 7.4 컨셉별 단가 표시

컨셉 3개마다 "촬영 n컷 / 스톡 n컷 / AI n컷 → 난이도 하·중·상". 효과가 비슷하면 촬영 적은 걸 고른다.

## 8. 만드는 순서

Script Studio(`index.html`)에 탭으로 추가한다. API 호출, 키 저장, 레퍼런스 톤, 히스토리를 재사용.

1. **레퍼런스 탭** ✅ (2026-09-30) — 링크 → Gemini 해부 → 포맷 카드 → 라이브러리. Gemini 키는 기존 입력칸과 공유, YouTube 키 칸 추가. 내보내기·가져오기, 참고 말투로 보내기 포함.
2. **상품 녹이기 탭** ✅ (2026-09-30) — 6.2~6.6. 레퍼런스 카드에서 "이 레퍼런스로 녹이기"로 바로 시작. 엔진은 OpenAI·Gemini·Claude 중 선택. 광고 표시 문구·제휴 고지·판매 링크는 코드가 자동으로 붙임. 기획 히스토리 저장.
3. **스토리보드·소스 탭** — 7장. Pexels/Pixabay 검색, SRT 내보내기.
4. **검수** — 기존 Script Studio 검수에 9장 항목 추가.
5. **쇼츠레이더 국가별 수집 + 기회 지수** — 4장. 별도 코드(사용자 PC). GitHub에 올리거나 `claude remote-control`로 열면 작업 가능.

## 9. 검수 체크리스트

- [ ] 무광고 테스트 통과 (상품 빼도 영상이 성립)
- [ ] 반전 위치 70~85%
- [ ] 상품 등장 2~3회, 항상 긍정 역할
- [ ] 영상 안에 구매·할인·링크 언급 없음
- [ ] 레퍼런스 대사·장면 복사 없음 (구조만)
- [ ] 나라별 광고 표시 문구 설명란·고정 댓글에 포함, 유튜브 "유료 프로모션" 체크
- [ ] 과장·금지 표현 없음 (기존 Script Studio 검수)
- [ ] 변화 간격이 레퍼런스 리듬 이내, 2초 이상 빈 구간 없음(빌드업 제외)
- [ ] 촬영 컷 3개 이하
- [ ] 자막 언어가 타깃 나라와 일치 (대만은 번체)
