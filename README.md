# tubechecker-studio

- `index.html` — 유튜브 대본 검수기
- `storage.html` — 이미지·영상 저장창고

## 이미지·영상 저장창고 (`storage.html`)

내 이미지·영상을 카테고리별로 모아 두고 바로 찾아 쓰는 보관함입니다. 대본 검수기 위쪽의 **저장창고** 버튼으로 들어가며, 접속 코드는 대본 검수기와 같습니다.

- 기본 카테고리: 동물 · 물고기 · 공룡 · 식물(꽃·나무·풀·잎) · 계절(봄·여름·가을·겨울). **편집**에서 추가·이름 변경·순서 변경·삭제할 수 있습니다.
- 한 파일을 여러 카테고리에 넣을 수 있습니다 (예: 벚꽃 사진 → 꽃 + 봄). 큰 카테고리를 누르면 안의 작은 카테고리 파일까지 함께 보입니다.
- 올리기: 파일 선택, 화면에 끌어다 놓기, Ctrl+V 붙여넣기, 폴더 통째로 올리기(폴더 이름과 같은 카테고리에 자동 분류), zip 파일.
- 찾기: 이름·태그·메모·카테고리 검색, 초성 검색(ㄱㅇㅇ → 고양이), 이미지/영상 필터, 즐겨찾기, 최근 사용.
- 쓰기: 다운로드, 이미지 복사(바로 붙여넣기), 휴대폰에서는 공유. 여러 개 골라서 분류·다운로드(zip)·삭제.

### 저장 위치와 백업

파일은 서버가 아니라 **지금 쓰는 브라우저 안(IndexedDB)** 에 저장됩니다.

- 다른 컴퓨터·휴대폰·브라우저에서는 보이지 않습니다. 같은 주소로 열어야 같은 파일이 보입니다.
- 브라우저에서 쿠키 및 사이트 데이터를 지우면 함께 지워집니다.
- **백업 · 옮기기**에서 백업 파일(zip)을 만들어 두세요. 카테고리별 폴더로 정리돼 있어 압축을 풀어 바로 쓸 수 있고, 다른 기기에서 불러오면 카테고리·태그·메모까지 그대로 복원됩니다.
